## Material findings and repairs

1. **Invalid GLMM likelihood comparisons (reproduced, repaired).** Two fresh joint-Laplace fits with 56 different response values but the same response name and row count produced chi-square 97.711 and p=4.841205e-23. The comparison now verifies data, likelihood family/approximation, weights, offsets, random design and fixed-effect nesting before producing an ordinary chi-square test. Changes in random covariance structure are refused rather than assigned the ordinary fixed-effect reference distribution. Equivalent random-term spellings can be conservatively refused; this is an explicit limitation, not silent inference.
2. **Uncertified population GLMM confidence intervals (reproduced, repaired).** A singular profiled binomial fit refused coefficient inference and conditional uncertainty but supplied 240 finite population confidence intervals without qualification. The fixed-only Wald route now uses the central capability arbiter. Unavailable uncertainty is NA with its reason; working-Hessian opt-in carries method/status/reliability. The engine's separately certified conditional-prediction route is preserved.
3. **Merge would lose durable fitted-state semantics (resolved).** Main's fast handle path fell back to optimization after deserialization. The incoming branch instead persisted and restored an engine-owned snapshot. The merge combines live-handle reuse with snapshot restoration; controls and the R-side response cannot silently replace the recorded query baseline. Tests cover original objectives, coefficients, uncertainty, missing/corrupt snapshots and a fresh child process. Actual refits remain appropriate for explicitly different estimands, such as REML to ML.
4. **Joint GLMM bootstrap refusal was obsolete (resolved).** The retained engine supports estimator-preserving refits. The wrapper now exposes this support while retaining thread controls, template objective, effective-estimator provenance and replicate accounting. Failed replicates remain visible.
5. **Documentation drift (repaired).** Corrected simulation availability, singularity semantics, Wald spelling, empirical versus grid averages, case weighting, stale README output and undefined data. Historical speed/calibration results are marked with their revision boundaries; adverse calibration results and estimand differences are retained.
6. **HTML truncation in a rendering dependency (reproduced, contained).** Under C locale, albersdown 2.1.0 produced a successful render whose HTML stopped inside JavaScript before a Unicode command symbol: 73,177 bytes and no closing HTML tag, versus 349,865 bytes under UTF-8. The failure is in its UTF-8 text-connection write. The six CRAN vignettes use rmarkdown::html_vignette; the four website articles retain albersdown and were rendered and inspected under UTF-8. The dependency defect remains outside this repository.
7. **Legacy covariance helper (repaired, not a public simulation defect).** The dead internal mm_rmvnorm fallback applied its eigenbasis on the wrong side. Fixed the covariance factor and added a rank-one support invariant. Current public simulation uses the newer PSD helper and already had the weighted/zero-component repairs; the earlier stale-checkout findings are not current public defects.
8. **Bootstrap LRT null baseline replacement (reproduced, repaired).** The native bridge reused the alternative but cold-refitted the null with the alternative's controls. A deliberately underoptimized null produced observed LRT 28.66004 instead of the supplied fits' 28.663. The bridge now accepts both fitted handles; a regression covers distinct controls and a serialized null. This demonstrates baseline replacement, not an error between two well-converged fits.
9. **Free-dispersion comparison policy (reproduced, repaired).** Gamma moment and legacy dispersion fits previously passed comparison guards despite different procedures (chi-square 32.322, p=1.307e-8 in a bounded fixture). Fits now record normalized fit-time policy; LRTs require matching known policy. Defaults and explicit moment are equivalent, whereas legacy and differing degrees-of-freedom corrections are refused.
10. **Regeneration removed the refit export (reproduced, repaired).** Latest main exported refit in NAMESPACE but lacked its roxygen @export annotation. Regeneration during the sweep removed the export; source-loading tools masked the issue. Clean vignette and help-example execution exposed it. The annotation and generated export are restored. The vignette also uses the supported lme4::refit generic explicitly. The release gate now retains complete build/install/check output and suite results for diagnosis.
11. **Release lint findings (repaired).** Fixed local F-variable naming, two formula-scope lint false positives by supplying explicit plot data, and minor formatting without weakening the lint policy.

## Remaining release boundaries

- Refresh hosted and builder evidence for the final merged candidate before submission; earlier platform results do not qualify changed R/native bridge code.
- Historical calibration does not establish every family, design, boundary state or uncertainty procedure at the retained engine pin. The regression and parity suite provides bounded numerical evidence, not a universal equivalence or calibration theorem.
- **Blocker: restored native models lose cancellation.** Executed offline Rust public-API reproducer at the pinned engine revision: LMM and GLMM live models returned Interrupted; restored models completed both bootstrap replicates despite the armed host callback. No public setter can reattach it without optimization. Upstream Mote bug bd-01M5WB5Y705MEEDTH28KDBWDWT contains the complete reproducer and acceptance contract; wrapper follow-up bd-01M5WCP9PDSE6MKK9QB14KDEBR tracks adopting the repair. Repair upstream, publish the pinned commit, re-vendor and retest callback attachment before treating restored long jobs as release-qualified. No upstream source was modified in this sweep.
- Documentation, code review and executable fixtures are a broad release sweep, not an exhaustive proof of the Rust engine or every ecosystem combination.
